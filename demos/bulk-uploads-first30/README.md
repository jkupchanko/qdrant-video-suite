# Bulk Uploads, first 30 seconds, every skill applied

A raw Zoom take of the "Bulk Uploading Data to Qdrant" script, edited by the suite. Two versions:

- `face_only_720.mp4` (32 s): the take cut to the script. Nine cuts chosen from the retakes by transcript,
  each on a word boundary; eye contact checked frame by frame on every chosen take; mirrored; black bars
  top and bottom to hide the Zoom tag; a slight alternating push (1.00 / 1.06) between cuts; 20 ms audio
  fades at each join. `cutlist.md` says which take each line came from.
- `suite_720.mp4` (32 s): the same cut with the other skills on top. Camera: FULL for the hook and the
  set-up line, NONE for five seconds under the dense/sparse line, FULL again for the reason. B-roll: the
  "Why Vector Type Matters" section of the Bulk Uploading docs page, recorded by the B-roll skill, finished
  in the house card. Transitions: cut everywhere; the one push the model videos use, the docs card sliding
  in from the right in 0.3 s; cut back to the face.

`script-with-camera-and-transitions.md` is the script with those calls written under the lines.
`broll-by-keyterm.md` is the key-term pass over the whole script against the docs page: which lines earn
an insert (eight of 42), which hold, which stay on the person.

Masters at 1080p are with the project files; these are 720p copies for review.
