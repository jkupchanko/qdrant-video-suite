# One Example

This example illustrates selection and layout.
It is not a completed script or a claim about measured results.

## The brief

A marketing team wants to compare a checklist, a shared calendar and a task board for producing a weekly newsletter.
They understand the work but have not decided how to organize responsibility and deadlines.
The video will run for about five minutes.
The available material is a description of the work and a demonstration of each option using the same planned newsletter.

## The recommendation

**Audience:** Marketers familiar with newsletter production.

**Funnel stage:** Consideration.

**Purpose:** Decide what to try for coordinating the next newsletter.

**Recommended structure:** The Comparison and Choice.

**Reason:** The viewer is choosing between alternatives rather than learning a sequence of dependent steps.
One shared task and a declared criterion make the differences understandable.

**What would change the choice:** If the viewer already selected a task board and wants to set it up, use The Guided Process.
If the video is about a repeated scheduling failure and its cause, use The Problem and Breakthrough.

## The layout

### 1. Decision and hook   0:00 to 0:15

**Purpose:** Establish the planning decision and the three options.

**Written hook:** Name the choice in a short on screen phrase.

**Verbal hook:** Explain the newsletter task and why a planning choice is needed.

[**Show:** The same planned newsletter beside the three approaches. **Transition:** Keep the newsletter visible while introducing the criterion.]

### 2. Criterion and follow up   0:15 to 0:45

**Purpose:** Explain the need to see deadlines and responsibility.

**Template:** [Planning choice] must make [deadlines and responsibility] visible to [the people doing the work].

[**Show:** The required handoffs and responsibilities. **Transition:** Carry the same requirements into the first option.]

### 3. Comparison   0:45 to 2:45

**Purpose:** Show how each option represents the same newsletter work.

**Template:** [Option] makes [relevant detail] visible in [specific way], with [observed tradeoff].

[**Show:** One approach at a time, followed by an aligned comparison. **Transition:** Retain the task and criterion while switching approaches.]

### 4. Conditions that change the choice   2:45 to 4:25

**Purpose:** Explain how team size or handoffs can affect the decision.

**Template:** When [work requirement] changes, [another option] may fit because [reason].

[**Show:** Two clearly labeled team situations. **Transition:** Return to the situation described in the brief.]

### 5. Recommendation   4:25 to 5:00

**Purpose:** Recommend the option supported by the team’s needs, or a small trial if evidence is insufficient.

**Template:** For [this team and task], start with [supported choice or trial] because [stated requirement].

[**Show:** The recommended next action and the criterion behind it. **Transition:** Finish on the decision introduced at the opening.]
