# Camera Plan for the Five Minute Search Video

[Source script](../../technical-video-script-library/Examples/miniCOIL%20Five%20Minute%20Script.md)

The supplied script leads this plan.
Its narration, seven section boundaries and two selected B roll requests stay in place.
The finer scene times below are proposed editing targets, not measurements from a recording.
Every presenter view can be represented by an empty rectangle.

## The camera sequence

| Time | Script moment | Layout and reason |
| :--- | :--- | :--- |
| 0:00 to 0:10 | Opening question | Presenter full screen to introduce the question. |
| 0:10 to 0:20 | Preview the language mismatch | Content full screen so the query and passage are clear. |
| 0:20 to 0:50 | Three prepared passages | Small top right inset beside the short passages, with an empty region reserved for it. |
| 0:50 to 1:02 | Why perro and dog can match | Keep the same inset while explaining a simple relationship. |
| 1:02 to 1:12 | Home and casa article illustration | Content full screen for the first selected B roll insert. |
| 1:12 to 1:25 | Context and shared concept | Restore the same inset outside the diagram labels. |
| 1:25 to 1:35 | Connect the idea to the code | Presenter full screen for the spoken handoff. |
| 1:35 to 2:35 | Encoding and search calls | Content full screen so code can be read. |
| 2:35 to 3:35 | Two actual searches | Content full screen so returned passages and ranks can be inspected. |
| 3:35 to 3:45 | Introduce the two meanings of bat | Presenter full screen for the short setup. |
| 3:45 to 3:57 | Bat article illustration | Content full screen for the second selected B roll insert. |
| 3:57 to 4:20 | Vocabulary limit | Restore the same inset beside short explanatory labels. |
| 4:20 to 4:35 | Three practice questions | Keep the same inset beside the simple practice card. |
| 4:35 to 4:45 | Return to checking results | Hide the inset while the result is brought back for inspection. |
| 4:45 to 5:00 | Closing invitation | Presenter full screen for the final two spoken sentences. |

This produces four planned full screen presenter appearances for this particular script.
It is not a default count for every five minute video.

## Inset size and framing

**Frame:** 1920 by 1080.

**Position:** Top right, consistently.

**Width:** 20% of the video frame, or 384 pixels.

**Height:** 288 pixels for the chosen 4:3 crop, about 26.7% of frame height.

**Crop and angle:** Head and shoulders, straight on.

**Normalized rectangle:** x 0.77, y 0.05, width 0.20, height 0.266667.

The full screen presenter uses a centered medium shot.
The inset needs reserved space outside the passage text, diagram labels and captions.
If that space is unavailable in the actual capture, hide the inset during that reading task.

## Where half screen could fit

An equal presenter and content split can fit a simple concept explanation with a few large labels.
The gallery illustrates that option with perro, dog and Shared concept.
It is not required in this plan.
The article inserts, code and results receive the full content frame because their details need to remain readable.

## Transition handoffs

Cut from the opening presenter to the query and intended passage.
Hide the inset for each selected article insert, then restore the same corner and crop.
Cut from the presenter handoff to the code.
Keep the face hidden while moving from code to actual results.
Return to the presenter for the closing invitation.

These directions describe the connection between views.
They do not require a slide, zoom, sound effect or added supporting clip at every change.
